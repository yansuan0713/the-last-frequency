The Last Frequency is a short arcade game about listening: you are the night operator of the last analog station on the coast, sliding a tuner along an FM dial to catch transmissions drifting in from the dark, decode them before they slip past, and piece together one stranger's five-night message — while keeping the needle clear of the red static. It runs from the static files in game/ in any desktop browser, with no build step and no network request; every sound is synthesised live with WebAudio.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
